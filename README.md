# Selective Fourier–Motzkin

**Code accompanying *[Communication-based operational principles bounding nonlocal correlations](https://arxiv.org/abs/2603.08610)***  
*Lucas Pollyceno, Denis Moraes, José Nogueira, Anubhav Chaturvedi, Rafael Rabelo, Marcin Pawłowski*

This repository implements the selective Fourier–Motzkin method introduced in the article and applies it to the non-signaling extreme points of the (4,4;2,2) Bell scenario.

## Usage

The script [main.py](https://github.com/dfmor/extreme-points/blob/main/main.py) applies the method to the causal structure of the simplest general communication scenario with two independent inputs. It also demonstrates how to use the following modules:

- [eliminate.py](https://github.com/dfmor/extreme-points/blob/main/eliminate.py) selects relevant inequalities from an initial set of constraints.
- [calculate_bounds.py](https://github.com/dfmor/extreme-points/blob/main/calculate_bounds.py) computes how tightly the generated inequalities bound isotropic behaviors in the associated Bell scenario.
- [auxiliary_functions.py](https://github.com/dfmor/extreme-points/blob/main/auxiliary_functions.py) provides the auxiliary functions used by the implementation.

The pickle file [class_matrix.pkl](https://github.com/dfmor/selective-fm/blob/main/class_matrix.pkl) contains all non-signaling extreme points of the (4,4;2,2) Bell scenario, grouped into equivalence classes and listed in lexicographic order.

## Results

For each equivalence class, the [results](https://github.com/dfmor/selective-fm/tree/main/results) directory provides:

- All nontrivial inequalities generated for the class.
- The number of inequalities selected and the constraints selected for each tested elimination order.
- The generated inequalities that give the tightest bounds on isotropic non-signaling correlations for that class.

The [number-violations](https://github.com/dfmor/selective-fm/tree/main/number-violations) directory reports how many inequalities generated by equivalence class *i* are violated by extreme points in class *j*. The filename identifies *i*, and each block within the file corresponds to a value of *j*.
